# Мировая Община

Ответственное, Целостное Участие в Общем Деле.

Проект общественного устройства, соединяющий общественную собственность, личную инициативу и персональную ответственность. Экономика Участия описывает хозяйственную модель; ПАРУС — её информационный учёт и планирование.
