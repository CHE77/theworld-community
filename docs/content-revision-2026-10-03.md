Проверены поздние поправки о квалификации, общем пропорциональном риске без отдельной предпринимательской прибыли, входном вкладе, внутреннем неотчуждаемом приросте и полном историческом перезачёте. Открытые параметры обозначены как открытые. Страница «Устав» — проект систематизации правил, а не утверждённый оригинал устава.

Переписаны семь обзорных русских страниц: главная, Община, Экономика Участия, кооперативы, планирование, ПАРУС и Устав.

Добавлены семь тематических страниц: квалификация; капитал; управление; участие, вход и выход; фонды; состояние проекта; словарь. Статус разработки отделён от целевой модели.

EN/UK остаются предварительными версиями с переходом на текущую русскую редакцию. Новые русские статьи не объявляются доступными переводами.

## Навигация и сборка

Основное меню дополнено тематическим меню. Русские статьи получают содержание с локальными ссылками. Таблицы прокручиваются в собственном контейнере. Сохранены прежние URL и переходы с renumeration-system-parus на parus.

В шаблоне используются фактические front matter lang и pageId. SITE_BASE_PATH учитывается в ссылках, ресурсах и старых meta-refresh переходах. Перед каждой сборкой очищается только генерируемый каталог _site, чтобы удалённые страницы не оставались в публикации.

Проверка: npm ci; npm run build; SITE_BASE_PATH=/theworld-community npm run build; целостность локальных ссылок, фрагментов и ресурсов; отсутствие старого файла после чистой сборки.
