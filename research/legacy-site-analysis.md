# Анализ legacy-site

## Что было обнаружено

- Основная копия сайта находится в папке `legacy-site/www.theworld.community/`.
- Внутри находится один основной HTML-файл: `index.html`.
- Внутри этого файла содержится единственная основная страница сайта Google Sites, а также навигационные ссылки на разделы:
  - `Community` / `Мировая Община`
  - `Participatory-Economy` / `Экономика Участия`
  - `Renumeration-System-PARUS` / `Система Учёта ПАРУС`
  - `Charter` / `Устав Общины`
  - главная страница

## Ключевые выводы

- Файлы в `legacy-site/` являются эталонным исходником и не должны изменяться.
- Служебные ресурсы Google Sites (CSS/JS/шрифты/внешние ссылки) не являются содержанием проекта и не должны переноситься автоматически.
- Основное содержимое проекта следует извлекать и переносить в Markdown-файлы внутри `src/content/`.
- Новая структура должна строиться независимо от Google Sites и публиковаться через GitHub Pages.

## Обнаруженные разделы сайта

1. Главная страница
2. Мировая Община
3. Экономика Участия
4. Система Учёта ПАРУС
5. Устав Общины

## Проблемы старой копии

- HTML и служебные данные Google Sites смешаны с содержанием.
- Содержимое не представлено в удобном для миграции структурированном виде.
- Много служебных ссылок и кода Google, не относящихся к новому сайту.
- Текстовые материалы должны быть аккуратно извлечены вручную из legacy-копии.
